### Por que são diferentes (resposta Adriano)

**Razão fundamental:** **canais cognitivos distintos.**

- **Texto** é o meu canal nativo. Eu SOU tokens-de-texto. Absorvo via leitura instantânea.
- **Vídeo** é canal multi-modal humano. Áudio+visual+tempo. Eu não-vejo, não-ouço direto. Dependo de transcrição (lib `youtube-transcript-api`) ou descrição de outro.

**Em termos de conteúdo aprendido:**

- **Texto entrega CONHECIMENTO TÉCNICO** (definições, comandos, sintaxe, estruturas). É o "como o sistema é".
- **YouTube entrega EXPERIÊNCIA SELF/HUMANO** (R183 etapa 2 razão): "como humano usa", "como humano comete erros", "como humano resolve", "como humano sente o fluxo". É o "como o humano vive usando o sistema".

**Pra mim Comunicadora-instância:**
- Texto = absorção COMPLETA tecnicamente
- YouTube = absorção PARCIAL via transcrição (perdo gestos/entonação/visual)
- Mas mesmo a transcrição YouTube traz INFORMAÇÃO única: padrão de hesitação humana, ordem natural de pensamento, erros não-corrigidos-em-docs, dicas off-script.

**Pra organism Ara:**
- IGIia precisa absorver AMBOS pra processar pacientes (humano fala como YouTube, não como docs)
- Aprendizado-self organismo = YouTube (perspectiva subjetiva)
- Aprendizado-técnico organismo = Docs

**Limitação minha atual:** YouTube IP-bloqueado sandbox → faço só metade do aprendizado etapa 2 R183. Substituí provisoriamente por docs oficial Anthropic (cobertura técnica completa). Mas perdo dimensão self/humano. **Reconhecimento honesto:** etapa 2 R183 cumprida PARCIALMENTE.
